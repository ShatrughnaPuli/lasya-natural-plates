## 🏢 Executive Overview

**Lasya Natural Plates** is a premier manufacturing unit and wholesale export supplier specializing in heavy-duty, luxury disposable tableware engineered from 100% naturally shed areca palm leaf sheaths. Our zero-chemical, zero-plastic thermo-moulding process preserves organic natural textures while guaranteeing 4+ hours of leak-proof resistance for hot gravies, banquets, and heavy catering.

## 🚀 Local Development Setup

### 1. Clone the repository
```bash
git clone https://github.com/ShatrughnaPuli/lasya-natural-plates.git
cd lasya-natural-plates
```

### 2. Start the Frontend (Vite)
```bash
cd client
npm install
npm run dev
```
Access the application at: `http://localhost:5173`

### 3. Start the Backend API (Optional)
```bash
cd server
npm install
node server.js
```
API runs on: `http://localhost:5000`
